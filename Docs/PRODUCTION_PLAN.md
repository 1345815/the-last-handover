# 《末班交接》制作基线

## 项目承诺

- Windows 短篇恐怖游戏，目标流程 15–20 分钟。
- 固定驾驶位；玩家不能下车，不做车辆物理。
- 核心机制是 N、1、2、3 档切换速度与现实状态。
- 正式内容只包含三个异常事件和一个循环结局。

## 里程碑

1. 原型：循环道路、观察、换挡、三种现实色调。
2. 垂直切片：一个完整站点、停车、车门、首次异常。
3. 内容：三个异常、交接手册、最终第五档。
4. 表现：驾驶室模型、低清 VHS、环境音、字幕。
5. 发布：Windows 构建、GitHub、itch.io 页面与素材声明。

## 删减顺序

第二结局 → 随机异常 → 复杂乘客动画 → WebGL。核心流程、三个异常和 Windows 构建不可删。
